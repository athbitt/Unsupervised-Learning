# Description of documents


### Column List documents_rawdata.csv

All the attributes were added manually by historians. This is real-life data, so it may contain missing values, typos, or different spellings. 

| # | Column Name | Description |
|---|-------------|-------------|
| 1 | `id` | Document ID |
| 2 | `abstract` | Editorial notes of a document |
| 3 | `analysis` | Analysis category of a document (who did the petitioner ask for A1: him/herself, A2: family) |
| 4 | `attachment_ids` | Describes with which documents (IDs) this document was sent as an attachment. |
| 5 | `cases` | Cases (individual fates) to which the document belongs |
| 6 | `doc_type` | Document type, there is always exactly one (in this subset filtered to letters only) e.g. letter (Brief), note |
| 7 | `doc_class` | Document class e.g. final version (Final), letter (Brief), draft (Entwurf), translation (Übersetzung) |
| 8 | `doc_style` | Document style e.g. handwritten (Handschriftlich), typewritten (Maschinenschriftlich) |
| 9 | `organisation_ids` | All organisations, institutions etc. mentioned in the documents |
| 10 | `person_ids` | All persons mentioned in the documents |
| 11 | `place_ids` | All places that are mentioned or linked in the document. |
| 12 | `author_id` | Organisation or person who wrote the document. Contains a person or organisation ID, e.g. P00232, I29392  |
| 13 | `date_when` | Exact date |
| 14 | `date_not_before` | Estimate (earliest possible date) |
| 15 | `date_not_after` | Estimate (latest possible date) |
| 16 | `creation_location` | Place where the document was written.
| 17 | `archive_location` | Location of the archive, place ID from the place register |
| 18 | `archive_iso_code` | ISO country codes |
| 19 | `archive_protno` | The different protocol numbers of the document. There are five different types, which can appear once or several times on a document. Documents without a number are marked as without protocol number ([Ohne Protokollnummer]) |
| 20 | `signature_archive` | Name of the archive |
| 21 | `signature_repository` | Holdings (collection) of the archive |
| 22 | `signature_file` | Specific file with folio reference of the document |
| 23 | `main_language` | Main language of a document; if there is only one language, it is automatically the main language. Values are German language names, e.g. German (Deutsch), Italian (Italienisch), French (Französisch) |
| 24 | `languages` | All other languages, e.g. in marginal notes. Values are German language names, e.g. Italian (Italienisch), German (Deutsch) |
| 25 | `raw_text` | The text body without HTML markers|
| 26 | `title` | Title of document: Bittschreiben, <sender> to (an) <recipient>, <date>
| 27 | `text_body` | The text body with HTML markers|


### Column List documents_enriched.csv

All attributes are retrieved from the raw text using named entity recognition (NER) and large language models.

| # | Column Name | Description |
|---|-------------|-------------|
| 1 | `id` | Document ID, links to `documents_rawdata.csv` |
| 2 | `date_extracted_from_text` | Date of the document as found in the text, usually in the format DD.MM.YYYY (e.g. 08.02.1940). Some entries are only a year (e.g. 1940) or contain notes (e.g. 15 Adar 5699 (approx. 06.03.1939)) |
| 3 | `location_extracted_from_text` | Place where the document was written, as found in the text. Free text, so the same place can appear in different spellings (e.g. Roma, Rome, Roma, Italy) |
| 4 | `what_is_requested` | What the petitioner asks for, e.g. a visa, financial aid, release from internment |
| 5 | `reason_of_request` | Why / in what context the petitioner makes the request, i.e. the personal situation described in the letter |
| 6 | `reason_for_persecution` | Reason why the person concerned is persecuted, e.g. Racial persecution (Jewish origin), Political persecution. Free text. Empty for about a third of the documents |
| 7 | `summary_keywords` | Comma-separated keywords describing the document (about 6 per document), e.g. emigration, Brazil, entry visa |
| 8 | `petitioner` | Name (and sometimes role) of the person or group who wrote the petition |
| 9 | `for_whom_is_requested` | Person(s) the request is made for, e.g. himself, his family, a named third person |
| 10 | `recipient` | Person or office the letter is addressed to, e.g. Pope Pius XII, Cardinal Luigi Maglione. Free text, so the same recipient can appear in different spellings |


### Column List documents_summaries.csv

The summaries are generated by a language model (GPT-4o) and haven't been checked.

| # | Column Name | Description |
|---|-------------|-------------|
| 1 | `id` | Document ID, links to `documents_rawdata.csv` |
| 2 | `gpt4o_summary` | One-sentence summary of the document (about 28 words), generated with GPT-4o |
